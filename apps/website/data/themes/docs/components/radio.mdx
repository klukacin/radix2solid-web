```jsx live=true
	<Flex asChild gap="2">{target => target(Text, {

      })}</Flex>

	<Flex asChild gap="2">{target => target(Text, {
        "as": "label",

        children: <>

		</>
      })}</Flex>
</Flex>
```

## API Reference

This component is based on the `input` element and supports [common margin props](/themes/docs/overview/layout#margin-props).

## Examples

### Size

Use the `size` prop to control the radio button size.

```jsx live=true
<Flex align="center" gap="4">
	<Flex gap="2">
		<Radio size="1" name="size-1" value="1" defaultChecked />
		<Radio size="1" name="size-1" value="2" />
	</Flex>

	<Flex gap="2">
		<Radio size="2" name="size-2" value="1" defaultChecked />
		<Radio size="2" name="size-2" value="2" />
	</Flex>

	<Flex gap="2">
		<Radio size="3" name="size-3" value="1" defaultChecked />
		<Radio size="3" name="size-3" value="2" />
	</Flex>
</Flex>
```

### Variant

Use the `variant` prop to control the visual style of the radio buttons.

```jsx live=true
<Flex align="center" gap="4">
	<Flex gap="2">
		<Radio variant="surface" name="surface" value="1" defaultChecked />
		<Radio variant="surface" name="surface" value="2" />
	</Flex>

	<Flex gap="2">
		<Radio variant="classic" name="classic" value="1" defaultChecked />
		<Radio variant="classic" name="classic" value="2" />
	</Flex>

	<Flex gap="2">
		<Radio variant="soft" name="soft" value="1" defaultChecked />
		<Radio variant="soft" name="soft" value="2" />
	</Flex>
</Flex>
```

### Color

Use the `color` prop to assign a specific [color](/themes/docs/theme/color).

```jsx live=true
<Flex as="span" gap="2">
	<Radio color="indigo" value="indigo" defaultChecked />
	<Radio color="cyan" value="cyan" defaultChecked />
	<Radio color="orange" value="orange" defaultChecked />
	<Radio color="crimson" value="crimson" defaultChecked />
</Flex>
```

### High-contrast

Use the `highContrast` prop to increase color contrast with the background.

```jsx live=true
<Grid columns="5" display="inline-grid" gap="2">
	<Radio color="indigo" value="indigo" defaultChecked />
	<Radio color="cyan" value="cyan" defaultChecked />
	<Radio color="orange" value="orange" defaultChecked />
	<Radio color="crimson" value="crimson" defaultChecked />
	<Radio color="gray" value="gray" defaultChecked />

	<Radio color="indigo" value="indigo" defaultChecked highContrast />
	<Radio color="cyan" value="cyan" defaultChecked highContrast />
	<Radio color="orange" value="orange" defaultChecked highContrast />
	<Radio color="crimson" value="crimson" defaultChecked highContrast />
	<Radio color="gray" value="gray" defaultChecked highContrast />
</Grid>
```

### Alignment

### Disabled

```jsx live="true"

		<Flex asChild gap="2">{target => target(Text, {

          "size": "2",
          children: <>
				<Radio name="enabled" value="1" defaultChecked />
				On
			</>
        })}</Flex>
		<Flex asChild gap="2">{target => target(Text, {
          "as": "label",
          "size": "2",
          children: <>
				<Radio name="enabled" value="2" />
				Off
			</>
        })}</Flex>
	</Flex>

	<Flex align="start" direction="column" gap="1">
```
