# Command

<Description>Use the same native action primitive inline and inside Dialog.</Description>

```tsx live=true
() => <Card style={{ width: "min(100%, 480px)" }}><CommandDemo /></Card>
```

The application filters its own action data; Command only manages the active result and input interaction. Search **Create note** and press Enter: one action runs and the surrounding form is not submitted. **Protected action** cancels before side effects. **Unavailable action** is disabled but still a result, not an empty list.

Opening the palette explicitly resets search and focuses its input. Dialog supplies the title, description, modal containment and Escape restoration. The action handler checks cancellation, requests close, then performs the action. Turn off **Accept palette close proposals**: an accepted action still runs once even though the palette remains open.

**Open details** opens a second actual Dialog. Palette restoration is prevented for that focus hand-off; it must not pull focus back from the new modal. No global keyboard shortcut, routing service or async-action engine is installed.

See the [native API and all three standalone styling downloads](/primitives/docs/components/command). This recipe requires the [rc.3 source candidate](/themes/docs/overview/getting-started), not the previously published rc.2. For accepted form keys rather than actions, use [Combobox](/themes/docs/recipes/combobox).
