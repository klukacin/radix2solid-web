# RadialBarChart

`RadialBarChart` is the polar container for `RadialBar` series. It owns the
chart's layout, scales, and interaction state; children like `PolarAngleAxis`, `PolarRadiusAxis` and `RadialBar` register themselves into it.

```tsx live=true
() => {
	const data = [
		{ name: "Visited", value: 1000, fill: "var(--accent-9)" },
		{ name: "Signed up", value: 640, fill: "var(--accent-8)" },
		{ name: "Activated", value: 410, fill: "var(--accent-7)" },
		{ name: "Paid", value: 180, fill: "var(--accent-6)" },
	];
	return <ResponsiveContainer width="100%" height={300} initialDimension={{ width: 560, height: 300 }}>
		<RadialBarChart data={data} innerRadius="25%" outerRadius="95%" title="Conversion steps">
			<RadialBar dataKey="value" background />
			<Tooltip />
		</RadialBarChart>
	</ResponsiveContainer>;
}
```

## Props

| Prop                        | Type                           | Default          | Description                                         |
| --------------------------- | ------------------------------ | ---------------- | --------------------------------------------------- |
| `data`                      | `object[]`                     | —                | Source data array, one entry per radial bar         |
| `width`, `height`           | `number`                       | —                | Fixed size (omit when inside `ResponsiveContainer`) |
| `margin`                    | `{ top, right, bottom, left }` | `{ 5, 5, 5, 5 }` | Space around the plot area                          |
| `syncId`                    | `string`                       | —                | Sync tooltip across charts sharing the id           |
| `cx`, `cy`                  | `number \| string`             | `"50%"`          | Center position of the chart                        |
| `startAngle`, `endAngle`    | `number`                       | `0`, `360`       | Angle range swept by the bars                       |
| `onClick`, `onMouseMove`, … | `function`                     | —                | Chart-level mouse events with the active payload    |

The base props follow the Recharts 3.9.2 `RadialBarChart` API (reference commit `b3451050`) that solid-recharts tracks; see the [Recharts RadialBarChart reference](https://recharts.org/en-US/api/RadialBarChart). The [next-suite release scope](/charts/docs/overview/releases) lists selected adaptations, not full Recharts 3.10.1 parity.

## Notes

- The default `layout` is `"radial"`, rendering bars radiating outward from the center.
- Each data entry renders as one radial bar sector.
- Use `PolarAngleAxis` and `PolarRadiusAxis` to label the angle and radius dimensions.
- Set `background` on the `<RadialBar>` child to render background sectors behind each bar.
