# FunnelChart

`FunnelChart` is the cartesian container for `Funnel` series. It owns the
chart's layout, scales, and interaction state; children like `Tooltip` and `Legend` register
themselves into it.

```tsx live=true
() => {
	const data = [
		{ name: "Visited", value: 1000, fill: "var(--accent-9)" },
		{ name: "Signed up", value: 640, fill: "var(--accent-8)" },
		{ name: "Activated", value: 410, fill: "var(--accent-7)" },
		{ name: "Paid", value: 180, fill: "var(--accent-6)" },
	];
	return <ResponsiveContainer width="100%" height={300} initialDimension={{ width: 560, height: 300 }}>
		<FunnelChart title="Signup funnel">
			<Tooltip />
			<Funnel dataKey="value" data={data}>
				<LabelList position="right" dataKey="name" fill="var(--gray-12)" stroke="none" />
			</Funnel>
		</FunnelChart>
	</ResponsiveContainer>;
}
```

## Props

| Prop                        | Type                           | Default          | Description                                         |
| --------------------------- | ------------------------------ | ---------------- | --------------------------------------------------- |
| `width`, `height`           | `number`                       | —                | Fixed size (omit when inside `ResponsiveContainer`) |
| `margin`                    | `{ top, right, bottom, left }` | `{ 5, 5, 5, 5 }` | Space around the plot area                          |
| `onClick`, `onMouseMove`, … | `function`                     | —                | Chart-level mouse events with the active payload    |

The remaining props follow the Recharts 3.9.2 `FunnelChart` API (reference commit `b3451050`) that solid-recharts tracks; see the [Recharts FunnelChart reference](https://recharts.org/en-US/api/FunnelChart). Changes from Recharts 3.10.1 are tracked but not ported.

## Notes

- `FunnelChart` is a cartesian chart that does not use axes. It is compatible with
  `Tooltip` and `Legend` children.
- Use `Funnel` to render the series; it handles all trapezoid geometry
  and event dispatch.
